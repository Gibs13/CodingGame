# CodinGame Bot Battle Testing

This repository is for testing bots in CodinGame bot-battle games with **cg-brutaltester**.

## Requirements

- Java, compatible with the downloaded JAR files
- The `cg-brutaltester.jar` release
- The `referee.jar` for the game you want to test

## Setup

1. Download `cg-brutaltester.jar` from the cg-brutaltester project releases.
2. Download the matching `referee.jar` for your CodinGame bot-battle game (list available on the cg-brutaltester page).
3. Place both JAR files in this repository, or note their locations for your configuration.
4. Configure cg-brutaltester to use the referee and provide the commands for launching the bots.

## Running tests

Run cg-brutaltester with Java, using the referee and bot commands configured for your game. Refer to the documentation included with the cg-brutaltester release for the command-line options and configuration format.
